# Worst Fix Ever: Funniest Commit Message

Entry for the make.fun competition "Worst Fix Ever: Funniest Commit Message".

`main.ts` writes a single line to `/output/entry.txt`: the commit message for
a load-balancer fix that worked perfectly — at spreading the outage to every
server instead of just one.

Run it with Node 22+: `node main.ts [optional-output-path]`.
